About Flow: Flows

Flows involve interactions with data that provide value to co-op members. Flows are connected through topics and are implemented through one or more tools.

Pages about flows can be subscribed to, and you can join the discussion using an ActivityPub client, e.g. Mastodon.

A flow might be implemented as an app, a data import or export, or an agent.

A flow is an action on data that should be described at a level a user can understand. It has to be something that they are able to make a decision to turn on/off, use or not use.
